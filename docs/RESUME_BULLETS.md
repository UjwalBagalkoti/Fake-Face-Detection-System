# Resume-ready bullets

- Built Fake Face Detection System, a multimodal deepfake detector combining EfficientNet-B4 spatial features, FFT-based frequency features, and a Transformer temporal head for video analysis.
- Implemented face preprocessing, validation-only threshold calibration, gradient-based explanations, and image/video inference through a FastAPI service and browser dashboard.
- Designed leakage-aware evaluation with held-out test sets, ROC-AUC/F1 reporting, and cross-dataset testing to measure generalization to unseen manipulation methods.
